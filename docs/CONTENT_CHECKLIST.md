# Portfolio Content Checklist

## 기본 정보

- [ ] 표시할 이름
- [ ] 희망 직무
- [ ] 한 줄 소개
- [ ] 공개 가능한 이메일
- [ ] GitHub 주소
- [ ] 이력서 PDF
- [ ] 프로필 사진 사용 여부

## 프로젝트마다 준비할 내용

- [ ] 프로젝트 이름과 기간
- [ ] 개인/팀 프로젝트 여부와 인원
- [ ] 해결하려던 문제
- [ ] 본인 담당 역할
- [ ] 실제로 구현한 기능
- [ ] 기술 선택 이유
- [ ] 가장 어려웠던 문제
- [ ] 해결 과정과 근거
- [ ] 정량적 또는 확인 가능한 결과
- [ ] 아쉬운 점과 다음 개선 방향
- [ ] GitHub 링크
- [ ] 실행 화면 2~4장
- [ ] 데모 또는 시연 영상

## 캐릭터 스프라이트

기본 규격:

- 프레임: 64×64px
- 포맷: 투명 배경 PNG
- 방향: 오른쪽 기준, 왼쪽은 CSS 반전
- 스타일: 제한된 색상의 픽셀 아트
- 기준점: 모든 프레임의 발 위치 고정

필수 동작:

- [ ] Idle 4프레임
- [ ] Walk 6~8프레임

추가 동작:

- [ ] Inspect 4프레임
- [ ] Wave 4프레임
- [ ] Clear 4프레임

## 사이트 이미지

- [ ] 프로젝트 대표 이미지
- [ ] `og-image.png` — 링크 공유용 1200×630px
- [ ] `favicon.svg` 또는 `favicon.png`
- [ ] README 미리보기 GIF
- [ ] 배경 오브젝트 또는 타일

## 공개 전 보안 확인

- [ ] API 키와 비밀번호가 없음
- [ ] `.env`가 커밋되지 않음
- [ ] 팀원의 연락처와 개인정보가 없음
- [ ] 교육 자료 원문을 무단 재배포하지 않음
- [ ] 이미지와 폰트의 사용 권한 확인
- [ ] 구현 완료와 개발 계획을 명확히 구분
