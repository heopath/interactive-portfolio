# MINJAE.DEV — Interactive Portfolio

허민재의 학습 과정과 프로젝트 경험을 횡스크롤 여정으로 표현한 인터랙티브 포트폴리오입니다.

## 실행

```bash
npm install
npm run dev
```

## 구성

- 방향키 또는 화면 버튼으로 이동하는 횡스크롤 탐색
- Java → Database → Spring → Team Project → AI 성장 서사
- 프로젝트 상세 모달과 GitHub 연결
- 채용 담당자를 위한 빠른 보기
- 모바일 반응형 및 모션 감소 접근성 지원
